
# Therapeace Massage Website

## Project Overview

Therapeace Massage is a website development project
created as part of my PFD200 Professional Development
module at university.

The aim of this project is to design and develop a
responsive website for a massage therapy business.

This project will help me improve my front-end
development skills and gain practical experience
in building websites from scratch.

## Technologies

The technologies I plan to use are:

- HTML5 – Website structure and content
- CSS3 – Styling, colours and responsive design
- JavaScript – Interactive website features
- GitHub – Version control and project documentation

## Planned Features

The website will include:

- Homepage
- About Us section
- Massage services and prices
- Contact information
- Booking button
- Mobile-friendly design

## Project Development

I will develop the website in stages:

1. Create the GitHub repository.
2. Build the homepage using HTML.
3. Style the website using CSS.
4. Add the services and contact sections.
5. Improve the layout for mobile devices.
6. Add interactive features using JavaScript.
7. Test the website and fix any errors.

I will regularly upload my progress to GitHub,
using commits to document each development stage.

## How to Run the Website

Once the homepage has been created:

1. Download or clone this repository.
2. Open the index.html file in a web browser.
